# HTTPS

Kiri 可为本地域名提供 HTTPS 支持，便于在本地开发中使用与生产更接近的安全上下文（如 Secure Cookie、部分浏览器 API 要求等）。

## 工作方式

- Kiri 提供本地证书颁发机构（CA）并为 `*.kiri.local` / 相关本地域名签发证书。
- 将 Kiri 的 CA 安装并信任到系统/浏览器后，浏览器访问 `https://<name>.kiri.local` 等地址时可显示为受信任连接（具体步骤与支持范围以版本与平台为准）。

## 启用步骤（通用）

1. 在 Kiri 中启用域名功能（见 [域名](/features/domains/)）。
2. 在设置或引导流程中安装/信任 Kiri 的本地 CA。
3. 确保目标容器服务可通过对应域名与端口访问。
4. 使用 `https://` 访问容器域名。

> 不同操作系统与浏览器对证书信任链的处理不同；若遇到“不受信任”提示，请检查 CA 是否已正确安装到当前用户或系统信任库。

## 与端口设置的关系

- 若在域名设置中自定义了 HTTPS 端口，访问地址需包含该端口（例如 `https://app.kiri.local:8443`）。
- 容器发布的 443 端口与名称服务端口可能存在占用/让出关系，具体以当前版本行为为准。

## 注意事项

- 本地 CA 仅用于本机开发信任，请勿将其私钥或证书用于生产环境。
- 某些工具或运行时可能使用独立证书库，需要单独配置信任。
- 若仅需快速访问且不要求 HTTPS，可优先使用 `http://<name>.kiri.localhost`。
