# 窗口

Kiri 提供图形界面用于查看和管理容器、镜像、卷、网络、构建、Kubernetes 等资源（可用视图因平台与版本而异）。

## 主要区域

- **侧边栏**：在不同资源视图间切换，如 Containers、Images、Volumes、Networks、Builds、Kubernetes（Pods/Services）、Share、Settings 等。
- **状态栏**：通常显示版本、引擎/VM 状态、资源使用、当前 `docker` 上下文指向等信息，并可能提供终端入口或反馈入口。
- **列表与详情**：资源列表支持查看状态、端口、镜像、创建时间等；点击条目可查看详情与操作。

## 容器（Containers）

- 查看运行中/已停止容器，执行启动、停止、重启、删除等操作。
- Compose 项目下的容器可按项目分组展示与批量操作（视版本）。
- 容器行可显示本地域名/端口、资源占用等信息；支持打开日志、终端、文件等入口（视版本）。

## 镜像与构建（Images / Builds）

- **Images**：查看本地镜像、标签与大小；支持拉取镜像、查看拉取进度、取消拉取（视版本）。
- **Builds**：查看构建记录与步骤、镜像层信息与相关操作（如扫描/清理缓存，视版本）。

## 卷与网络（Volumes / Networks）

- 管理命名卷与网络资源，查看使用情况与关联信息。

## Kubernetes

- 在启用内置集群后，可在窗口中查看 Pods、Services 等对象并进行基本管理。

详见 [Kubernetes](/guide/kubernetes/)。

## Share 与设置

- **Share**：管理公网分享链接、查看用量与计划（需登录 Kiri Cloud）。
- **Settings**：外观、资源、网络、域名、构建、导入等配置。

详见 [Kiri Share](/features/share/)、[Kiri Cloud](/features/kiri-cloud/) 与 [设置](/guide/settings/)。

## 终端（部分版本）

- 0.1.18 起窗口可打开内置终端，支持标签、分屏、搜索等，且将 Kiri 的 `docker` 置于 PATH 前（以实际版本为准）。

## 语言与显示

- 0.2.0 起支持多语言界面与首次启动语言选择；可在设置中更改。
- 视图菜单可调整文字大小；部分版本提供主题切换入口。

## 平台差异

- macOS：含菜单栏应用行为（关闭窗口可隐藏 Dock 图标但保持后台运行，视版本）。
- Windows：提供托盘图标与首次运行安装向导体验。
- Linux：完整包可提供窗口（`kiri ui`）；`kiri-lite` 与部分架构包可能无图形界面。
