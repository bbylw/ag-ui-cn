# Kiri Cloud

Kiri Cloud 是 Kiri 的账号体系。目前主要用于 [Kiri Share](/features/share/)；容器运行、Kubernetes、Linux 机器等核心功能无需账号即可使用。

## 账号提供什么

通过 GitHub 登录创建/使用账号后，同一账号可在多台电脑（Mac、Windows、Linux）上使用：

- **你的链接**：查看在任意已登录设备上创建的分享链接，并可从任意已登录设备断开。
- **保留名称**：为分享预留稳定名称（如 `demo.runkiri.cloud`），在重启后仍可复用（按计划与规则）。
- **计划与用量**：并发链接数、速率限制、月流量额度及当前用量，可在窗口 Share 视图或 `kiri share status` 查看。

## 登录与安全

- 登录通过 GitHub 授权完成，Kiri 不会获取你的 GitHub 密码。
- 每台设备的登录状态保存在本地（如 `~/.kiri/share.json`，仅当前用户可读）。
- 使用 `kiri share logout` 或窗口中的退出登录可移除该设备的登录状态。

## 日常管理

| 目的 | 窗口 | 命令行 |
| --- | --- | --- |
| 分享端口/容器 | 容器行的 Share | `kiri share PORT\|CONTAINER` |
| 查看/停止链接 | Share 视图 | 终端中 `Ctrl+C` 或视图操作 |
| 预留名称 | — | `kiri share reserve NAME` |
| 查看名称 | — | `kiri share names` |
| 释放名称 | — | `kiri share release NAME` |
| 查看计划与用量 | Share 视图 | `kiri share status` |

## 即将推出

官方提到将提供浏览器端的 Kiri Cloud 应用，用于在不打开 Kiri 客户端时查看账号下的链接、名称与用量等信息。届时仍使用同一 GitHub 账号与相同数据。

## 隐私提示

- 使用分享功能时，本地服务流量会通过 Kiri 的基础设施转发；请评估被分享内容的敏感性。
- 崩溃报告/诊断数据的收集与脱敏策略以应用内说明与 [设置](/guide/settings/)、[更新日志](/guide/whats-new/) 中的隐私相关条目为准。
