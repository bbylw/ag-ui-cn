# Linux 机器

Kiri 的 Linux 机器（Machines）功能可提供一个长生命周期的 Linux 环境，用于开发、测试或运行需要完整 Linux 用户态的任务（可用性与命令细节以平台与版本为准）。

## 基本概念

- 机器是独立于一次性容器的持久环境，可包含你的用户配置、安装的软件与工作目录。
- 在支持的场景下，宿主机目录（如 macOS 的 `/Users`）可在机器内以相同路径访问，便于直接在本地项目上工作。

## 常用命令

```bash
# 创建机器
kiri machine create dev

# 列出机器
kiri machine ls

# 进入 shell
kiri machine shell dev

# 停止/启动/删除
kiri machine stop dev
kiri machine start dev
kiri machine rm dev
```

> 具体子命令、参数与默认镜像/发行版可能随版本变化，请以 `kiri machine --help` 为准。

## 使用场景

- 需要一个“像虚拟机一样”可长期保留状态的 Linux 环境，但希望与 Kiri 的容器/网络体验集成。
- 在 macOS 上获得接近原生路径的 Linux 开发环境，减少路径映射带来的摩擦。
- 运行需要 systemd、特定内核能力或持续后台进程的开发工具链（以实际支持为准）。

## 与容器的区别

| 方面 | 容器 | Linux 机器 |
| --- | --- | --- |
| 生命周期 | 通常面向单进程/服务，可随时销毁重建 | 面向长期使用，可保留状态 |
| 使用方式 | `docker run/exec`、镜像驱动 | 交互式 shell、按需安装软件 |
| 适用场景 | 应用交付、服务编排 | 个人开发环境、实验环境 |

## 注意事项

- 机器会占用磁盘与运行时资源；不使用时可停止或删除。
- 文件共享、网络与端口暴露行为以当前版本实现为准；如需对外提供服务，可结合容器或端口转发方案。
- 在 Linux/Windows 平台上的支持范围与命令行为可能与 macOS 不同，请参考对应平台文档。
