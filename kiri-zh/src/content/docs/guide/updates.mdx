# 更新

Kiri 在 macOS 和 Windows 上支持应用内更新（具体行为因平台与版本而异）。Linux 目前通常通过下载安装包或未来的软件源更新。

## macOS 与 Windows

- Kiri 会定期检查更新（例如 0.1.18 起提到每 6 小时检查一次，在应用保持打开时）。
- 发现新版本后可在后台下载；窗口或托盘菜单中可能提供“检查更新”等入口。
- 下载完成后通常可选择**立即重启**安装或**稍后**（例如退出时安装）。
- 安装更新可能会停止正在运行的容器；设置了重启策略的容器在引擎重启后可按策略恢复。
- 在 Windows 上，引擎侧组件可能需要额外的“重启引擎”步骤以完成切换（以界面提示为准）。

## 更新源与校验

- 各平台/架构使用对应的更新 feed（例如按 arm64/x86_64 区分）。
- 下载的安装包会进行完整性与来源校验（如 SHA-256、签名或升级码/平台/版本校验，具体以版本实现为准）。
- Windows 安装包在部分版本中尚未代码签名时，系统可能提示确认运行；更新流程仍会执行其自身校验。

## Linux

- 当前通常通过从 [runkiri.com/download](https://runkiri.com/download/) 下载 `.deb` / `.rpm` 并安装来升级，或重新运行安装脚本。
- 文档提到计划提供签名的 apt/dnf 软件源（就绪后可通过包管理器升级）。
- 升级包安装后，为避免中断运行中的容器，引擎可能不会立即重启；可在合适时执行 `sudo systemctl restart kiri` 运行新版本（以实际环境为准）。

## 查看版本与变更

- 窗口状态栏通常显示当前版本号。
- Linux 可用 `apt list --installed kiri` 或 `rpm -q kiri` 等查看已安装版本。
- 完整变更记录见 [更新日志](/guide/whats-new/) 与官方网站发布页。
