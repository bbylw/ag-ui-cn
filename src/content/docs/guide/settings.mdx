# 设置

Kiri 的图形界面提供多类设置（具体选项因平台与版本而异）。以下为常见类别说明。

## 外观（Appearance）

- **主题**：可在浅色/深色等模式间切换（部分版本支持跟随系统）。
- **语言**：支持多语言界面（0.2.0 起提供 15 种语言），可在首次启动或设置中选择，界面文本跟随所选语言；来自 Docker 本身的部分状态文本可能仍为英文。
- **文字大小**：可在视图菜单或设置中调整。

## 资源（Resources）

- 查看引擎/VM 的运行状态与资源使用情况。
- 在 macOS 上可体现内存占用与休眠相关行为；在不同平台上展示项可能不同。
- 可能包含引擎开关（启动/停止）等控制（以实际版本为准）。

## 网络（Network）

- 代理等网络相关配置：可使用系统代理设置或自定义代理。
- 在 Windows + WSL 场景下，指向 Windows 本机 `127.0.0.1` 的代理可由 Kiri 转发至 Windows 侧代理（用于拉取镜像等）。

## 域名（Domains）

- 启用/配置容器本地域名（如 `.kiri.local` / `.kiri.localhost`）。
- 可配置容器名解析所使用的端口（0.2.0 起支持在设置中指定，默认 80/443）；变更后链接可能带端口。

详见 [域名](/features/domains/) 与 [HTTPS](/features/https/)。

## 构建（Builds）

- 选择普通 `docker build` 使用的构建器（Docker 或 Kiri），以便与其他引擎共存时控制构建去向。
- 查看与清理构建缓存等（视版本）。

详见 [构建](/docker/builds/)。

## Kubernetes

- 管理内置 Kubernetes 集群的启停与配置（视界面版本）。

详见 [Kubernetes](/guide/kubernetes/)。

## 导入（Import，macOS 等）

- 从 Docker Desktop 或 OrbStack 导入镜像、卷与容器到 Kiri。
- 可按类型选择要导入的项目；已存在于 Kiri 的项目会标记为不可重复导入。

详见 [从 Docker Desktop 迁移](/docker/migrate/)。

## 隐私与诊断

- 崩溃报告与诊断信息的发送策略、内容范围与脱敏说明以应用内提示与 [更新/隐私相关说明](/guide/updates/) 为准。
- 可通过 `kiri diag logs` / `kiri diag report` 获取本地诊断信息。

> 提示：设置项名称与位置可能随版本迭代调整，以上内容以当前发布版本界面为准。
