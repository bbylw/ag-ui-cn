`AGUI.Abstractions` 是 AG-UI .NET SDK 的协议类型包。它定义 AG-UI 客户端与服务端共享的事件、消息、工具、上下文、能力、中断与序列化类型。

```bash
dotnet add package AGUI.Abstractions
```

该包不对 HTTP、ASP.NET Core 或特定智能体运行时表态。它是 `@ag-ui/core` 在 .NET 中的对应物：事件流与请求载荷的稳定线路类型。

> **说明：** `AGUI.Abstractions` 面向 `net10.0`、`net9.0`、`net8.0`、`netstandard2.0` 与 `net472`。它兼容 AOT：可序列化的协议类型注册在源生成的 `AGUIJsonSerializerContext` 中。

## SDK 包结构

.NET SDK 拆成若干小包，使协议类型、线路格式、客户端代码与服务端代码可以独立采用。

| 包 | 用途 |
| --- | --- |
| `AGUI.Abstractions` | 协议事件、消息、工具、能力、中断与 JSON 序列化 |
| `AGUI.Formatting` | 事件流格式化抽象与 Server-Sent Events 支持 |
| `AGUI.Protobuf` | Protobuf 事件流格式化与二进制协议支持 |
| [`AGUI.Client`](/sdk/dotnet/client/overview/) | HTTP 客户端与 `IChatClient` 实现 |
| [`AGUI.Server`](/sdk/dotnet/hosting/overview/) | 从 `ChatResponseUpdate` 流到 AG-UI 事件的框架无关适配器 |

## 线路格式与协议对齐

JSON over Server-Sent Events 是完整保真的事件流。`AGUI.Formatting` 定义事件流格式化契约与 SSE 支持；`AGUI.Protobuf` 为共享 proto schema 覆盖的协议子集增加二进制事件流格式化。

协议对齐从 `AGUI.Abstractions` 开始。TypeScript 参考 SDK 新增或修改线路类型时，对应的 .NET 事件、消息、工具或能力类型应与 `AGUIJsonSerializerContext` 及兼容性夹具同步更新。

```bash
cd sdks/dotnet
dotnet test tests/AGUI.Abstractions.UnitTests/
dotnet test tests/AGUI.Formatting.UnitTests/
dotnet test tests/AGUI.Protobuf.UnitTests/
```

## 类型

- `RunAgentInput` — 运行智能体的输入载荷
- 消息类型 — 会话、工具、活动与推理消息
- `AGUIContext` — 提供给智能体的上下文信息
- `AGUITool` — 带 JSON Schema 参数的工具定义
- `AgentCapabilities` — 结构化的能力声明

多模态输入（文本、图像、音频、视频、文档与二进制）通过用户消息的内容片段表达。

## 事件

事件驱动智能体与前端的通信：

- 生命周期事件 — 运行与步骤追踪
- 文本消息事件 — 助手消息流式传输
- 工具调用事件 — 函数调用生命周期
- 状态管理事件 — 智能体状态与消息快照
- 推理事件 — 推理流支持
- 活动事件 — 结构化进度与临时 UI 状态
- 特殊事件 — 原始与自定义事件

事件语义（何时必须发、消费者必须接受什么）以[规范 1.0](/spec/1-0/) 为准；.NET 类型只是该规范的类型化映射。
