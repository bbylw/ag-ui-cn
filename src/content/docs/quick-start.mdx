本页带你在几分钟内完成安装并运行第一个容器。以下步骤以 **macOS** 为例；Linux 与 Windows 的安装方式见 [安装指南](/install/)，但 `docker` 命令用法一致。

## 安装并打开 Kiri

<Steps>
  <Step title="下载 Kiri">
    前往 [runkiri.com/download](https://runkiri.com/download/) 下载适合你设备的安装包（Apple silicon 或 Intel Mac）。也可以使用脚本安装：

    ```sh
    curl -fsSL https://runkiri.com/install.sh | bash
    ```
  </Step>
  <Step title="完成首次设置">
    首次打开 Kiri 时，它会自动完成初始化，例如：

    - 创建 `kiri` Docker context（指向 `~/.kiri/run/docker.sock`）
    - 配置登录后启动引擎
    - 将 `docker` 和 `kiri` 命令加入 `~/.kiri/bin`
    - 在合适的情况下创建 buildx builder

    打开一个**新的终端窗口**，让 PATH 更新生效。
  </Step>
  <Step title="选择容器访问方式">
    Kiri 会询问你如何访问容器：

    - **localhost**：按端口访问，如 `localhost:8080`
    - **.kiri.local**：按名称访问，如 `myapp.kiri.local`（需要一次管理员授权）

    无论哪种方式，容器通常也可通过 `http://<name>.kiri.localhost` 访问（无需额外配置）。
  </Step>
</Steps>

<Aside type="tip">
  如果你的 Mac 上已安装 Docker Desktop 或 OrbStack，Kiri 不会强行接管默认上下文。你可以使用 <code>docker context use kiri</code>，或直接使用 <code>kiri run</code> / <code>kiri ps</code> 等命令（它们始终指向 Kiri）。
</Aside>

## 运行第一个容器

启动一个 nginx 容器并映射端口：

```sh
docker --context kiri run -d --name web -p 8080:80 nginx
docker --context kiri ps
```

如果 Kiri 是当前默认 Docker 上下文，也可以直接使用：

```sh
docker run -d --name web -p 8080:80 nginx
```

## 通过名称访问

容器启动后，你可以通过多种方式访问：

```sh
open http://web.kiri.localhost   # 通常无需额外配置
open http://localhost:8080       # 按端口访问
# open http://web.kiri.local     # 如果启用了 .kiri.local 域名
```

## 启动一个 Compose 项目

在一个目录中创建 `compose.yaml`：

```yaml title="compose.yaml"
services:
  web:
    image: nginx
    ports:
      - "8081:80"
  redis:
    image: redis:7
```

然后启动：

```sh
docker --context kiri compose up -d
# 或
kiri compose up -d
```

Compose 服务可以通过类似 `<service>.<project>.kiri.localhost` 的名称访问（具体取决于你的域名设置）。

## 分享容器（可选）

登录后，你可以用 [Kiri Share](https://docs.runkiri.com/share/) 为容器生成公网 HTTPS 地址：

```sh
kiri share login
kiri share web
```
