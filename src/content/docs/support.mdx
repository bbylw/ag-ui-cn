AG-UI 是免费且开源的。请使用项目的公开支持渠道报告问题、提出改进、参与贡献或从社区获得帮助。

## 缺陷、功能请求与贡献

在 GitHub 上报告问题、提出改进或为 AG-UI 贡献代码：

[https://github.com/ag-ui-protocol/ag-ui/issues](https://github.com/ag-ui-protocol/ag-ui/issues)

## 社区问答与讨论

在 Discord 中提问，并向其他使用 AG-UI 的开发者学习：

[https://discord.gg/Jd3FzfdJa8](https://discord.gg/Jd3FzfdJa8)

## 生产环境支持

如果你的团队在生产部署中需要架构或实施帮助，可了解[生产环境支持](/production-support/)（可选的商业支持，与开源项目分开）。
