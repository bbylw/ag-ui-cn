# 菜单栏

在 macOS 上，Kiri 通常以菜单栏应用形式运行，提供引擎状态与快捷入口（具体菜单项随版本可能变化）。

## 常见功能

- **引擎状态**：显示 Kiri/VM 是否运行、休眠或已停止。
- **快速操作**：打开主窗口、访问设置、查看文档或反馈入口等。
- **容器/资源快捷入口**：部分版本可从菜单快速跳转到常用视图。

## 与窗口的关系

- 关闭主窗口不一定退出 Kiri：在较新版本中可能仅隐藏 Dock 图标，Kiri 继续在菜单栏运行，容器保持运行。
- 从菜单栏可重新打开窗口；完全退出应用通常会停止引擎与相关容器（以实际行为与提示为准）。

## Windows 托盘

Windows 上对应的是系统托盘图标，提供打开窗口、查看引擎状态、更新与退出等操作；右键菜单可显示运行中的容器并跳转到窗口页面。

> 说明：Linux 环境通常不使用 macOS 菜单栏模式；有图形界面时以窗口与系统集成方式为主。
