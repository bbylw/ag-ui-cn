# Kiri Share

Kiri Share 可以为本地运行的端口或容器生成一个公网 HTTPS 地址，方便演示、联调或让外部访问本地服务。

## 前提条件

- 需要 Kiri Cloud 账号（使用 GitHub 登录）。容器运行、Kubernetes、Linux 机器等其他功能不要求账号。
- 同一账号可在多台电脑上登录，分享链接与配额在账号维度统一管理。

## 创建分享

在终端中：

```bash
# 分享本地端口
kiri share 3000

# 或分享容器（按名称/标识，视版本支持）
kiri share <PORT|CONTAINER>
```

在窗口中：可在容器行点击 **Share**（视界面版本）。

分享创建后会返回一个 `https://...runkiri.cloud` 等形式的公网地址。保持运行分享的进程/会话即可持续提供访问（具体行为以版本为准）。

## 管理分享

- **查看与停止**：在窗口的 Share 视图可暂停、恢复或断开链接；在终端中运行的分享可用 `Ctrl+C` 停止。
- **跨设备管理**：已登录同一账号时，可在任意设备上查看并断开属于自己账号的链接。
- **保留名称**（如支持）：`kiri share reserve NAME` 预留名称，`kiri share names` 查看，`kiri share release NAME` 释放。
- **状态与用量**：`kiri share status` 或窗口中的 “This month” 查看计划、并发链接数、速率与流量用量。

## 计划与限制

- 账号计划决定同时可开启的链接数量、速度限制与月流量额度等；超出限制时需等待额度恢复或升级计划（以官方当前政策为准）。

## 安全注意事项

- 分享地址可被持有链接的人访问，请勿暴露包含敏感数据或管理接口的服务，或在分享前加上认证与访问控制。
- 分享会将流量经由 Kiri 的中继服务转发；仅在信任该机制与目标服务的情况下使用。
- 不再需要时及时断开分享。

## 登录与退出

```bash
kiri share login
kiri share logout
```

登录凭据保存在本机（如 `~/.kiri/share.json`，权限受限），`logout` 或窗口中退出可在该设备移除登录状态。

更多账号说明见 [Kiri Cloud](/features/kiri-cloud/)。
