# 容器文件

Kiri 可以将容器内的文件系统以只读方式暴露给宿主机，方便在图形界面或编辑器中查看容器内文件。

## macOS：`~/Kiri`

- 在 macOS 上，Kiri 通常将容器文件挂载/展示在用户主目录下的 `~/Kiri`。
- 视图内容会随容器文件系统变化保持更新（只读）。
- 若 `~/Kiri` 已存在用户文件或被其他挂载占用，Kiri 会避免覆盖并在界面中提示原因（以版本行为为准）。

## 使用场景

- 快速查看容器内配置文件、日志目录结构或构建产物位置。
- 在不进入容器 shell 的情况下确认文件是否存在、路径是否正确。
- 辅助调试挂载与工作目录问题。

## 与绑定挂载/卷的区别

- **绑定挂载（bind mount）**：将宿主机目录映射进容器，读写行为取决于挂载方式。
- **命名卷（volume）**：由引擎管理的持久化存储。
- **容器文件视图**：面向“查看容器内看到的文件系统”的便捷入口，通常为只读呈现，不应作为修改容器内文件的主要方式。

## 注意事项

- 请勿依赖该视图对容器内系统文件进行写入；如需修改，应在容器内操作或通过正确的挂载/构建流程完成。
- 大量小文件或频繁变更目录的展示性能可能受实现方式影响。
- 不同平台对文件暴露方式与路径可能不同，请以对应平台文档与实际版本为准。
