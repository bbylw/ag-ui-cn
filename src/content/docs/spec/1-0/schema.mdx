- **可读生成页**：[docs.ag-ui.com/spec/1-0/schema](https://docs.ag-ui.com/spec/1-0/schema)
- **机器可读文件**：[schema.json](https://docs.ag-ui.com/spec/1-0/schema.json)（`https://ag-ui.com/spec/1-0/schema.json`）

## 使用注意

- **结构以 schema 为准，行为以规范为准。** 两者冲突时，结构看 schema，行为看[规范](/spec/1-0/)。
- **运行时不使用严格 schema。** 接收路径应接受未识别内容并剥离，见[处理模型](/spec/1-0/basic/processing/)。
- schema 封闭协议自有对象，但 `metadata` 与 JSON Patch 操作按设计开放，其中的额外成员必须保留。
